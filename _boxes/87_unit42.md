<br />
The first step in this process is to identify the number of events with an Event ID 11 in the Event logs.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/eventeleven.png" title="Get Event ID 11" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Check the logs for all events where a process is created in memory and search for a executable that stands out as potential malicious.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/maliciousexecutable.png" title="Malicious Executable" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Start by finding the FileCreate event (Event ID 11) that creates the executable.  Scroll up from that record and find the DNS record (Event ID 22).  Check the EventData to get the domain.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/getdomain.png" title="Get Domain" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Search for a event with the Event ID 2.  Check the EventData for the PDF and not the CreationUtcTime.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/getpdftime.png" title="Get PDF Time" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Search for FileCreate and look ing EventData for the once.cmd file.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/oncecmd.png" title="once.cmd" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Check for the DNS requests (Event ID 22).  Look for the malicious file in the Image column.  Get the QueryName.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/queryname.png" title="Query Name" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Filter for Network connection using Event ID 3 and check the EventData for the DestinationIP.

<div class="row justify-content-sm-center">
    <div class="col-sm-8 mt-3 mt-md-0">
        {% include figure.liquid loading="eager" path="/assets/img/unit42/destip.png" title="Destination IP" class="img-fluid rounded z-depth-1" %}
    </div>
</div>

<br />
Filter for Process terminated using Event ID 5 and get the time stamp from EventData.
